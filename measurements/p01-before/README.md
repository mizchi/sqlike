# P01着手前の基準

`*-current.json`と`p0-completion.json`は、P0完了時点の記録をコピーしたもの。
`sqlite-speed-profile.json`はP01のコード変更直前にpoint / miss / constantのprofileを追加採取した。
`aot-phases-*.txt`は同時点の`moon bench`による分離probeの出力。

過去のソース・artifact hashを保持する比較用アーカイブであり、記録内の元パスが現在のビルドと一致することは求めない。現行の鮮度検査は親ディレクトリのレポートに対して実行する。

条件と採用判断は[結果の説明](../../docs/p01-aot-results.md)を参照。
